# 🤝 Guía de Contribución

¡Gracias por tu interés en contribuir a este proyecto! Las aportaciones de la comunidad ayudan a mantener y mejorar esta herramienta.

Por favor, tómate un momento para revisar esta guía antes de enviar tu contribución.

---

## 🚀 ¿Cómo puedo contribuir?

### 1. Reportar Errores (Bugs)
Si encuentras un error o un comportamiento inesperado:
1. Revisa si la incidencia ya ha sido reportada en la pestaña de **Issues**.
2. Si no existe, abre una nueva issue describiendo:
   - Pasos para reproducir el problema.
   - Comportamiento esperado vs. comportamiento actual.
   - Capturas de pantalla o detalles del navegador si aplica.

### 2. Proponer Nuevas Funcionalidades
Si tienes una idea para mejorar la aplicación:
1. Abre una issue proponiendo la mejora.
2. Explica claramente el caso de uso y el beneficio para los usuarios.

### 3. Enviar Cambios (Pull Requests)
Si deseas enviar código para solucionar un problema o agregar una característica:

1. **Haz un Fork del repositorio.**
2. **Crea una rama para tu función o corrección:**
   ```bash
   git checkout -b feat/nueva-funcionalidad
   # o para un error:
   git checkout -b fix/correccion-bug
